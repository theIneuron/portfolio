# Деплой портфолио и заявок в Telegram на Vercel

Сайт готов работать на Vercel без включённого компьютера. Главная страница будет статической, а `POST /api/contact` — серверной Vercel Function, которая отправляет заявку через Telegram Bot API.

## 1. Создать Telegram-бота

1. Откройте официального `@BotFather` в Telegram.
2. Выполните `/newbot`, задайте имя и username бота.
3. Сохраните выданный токен. Не отправляйте его в переписке и не добавляйте в исходный код.
4. Откройте созданного бота и нажмите **Start** — иначе бот не сможет первым написать вам.

Для начала проще отправлять заявки в личный чат. После сообщения боту получите `chat_id` через официальный метод `getUpdates`. Чтобы токен не остался в истории команд, в терминале можно использовать скрытый ввод:

```bash
read -s PORTFOLIO_BOT_TOKEN
curl -s "https://api.telegram.org/bot${PORTFOLIO_BOT_TOKEN}/getUpdates"
unset PORTFOLIO_BOT_TOKEN
```

В ответе найдите значение `message.chat.id`. Позже можно создать закрытую группу «Заявки с сайта», добавить туда бота и использовать ID этой группы.

## 2. Развернуть проект

Вариант через Git удобнее для автоматических обновлений:

1. Закоммитьте и отправьте текущие изменения в репозиторий.
2. В Vercel выберите **Add New → Project** и импортируйте репозиторий `portfolio`.
3. Framework Preset должен определиться как **Next.js**.
4. Root Directory оставьте корнем репозитория (`./`).
5. Выполните первый Deploy.

Можно использовать и Vercel CLI: `vercel` для Preview и `vercel --prod` для Production.

## 3. Добавить переменные окружения

Откройте **Project → Settings → Environment Variables** и добавьте для окружения **Production**:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather, пометьте как Sensitive;
- `TELEGRAM_CHAT_ID` — ID личного чата или закрытой группы;
- `CONTACT_HASH_SALT` — случайная строка; можно создать командой `openssl rand -hex 32`.

Если подключите собственный домен и сайт будет доступен с нескольких адресов, добавьте:

```text
CONTACT_ALLOWED_ORIGINS=https://example.uz,https://www.example.uz
```

Стандартные адреса Vercel определяются сервером автоматически. Эти переменные нельзя называть с префиксом `NEXT_PUBLIC_`.

После добавления или изменения переменных обязательно выполните **Redeploy**: старые deployments не получают новые значения автоматически.

## 4. Проверить после публикации

1. Откройте production-адрес сайта.
2. Отправьте тестовую заявку.
3. Убедитесь, что на сайте появился номер заявки вида `BZ-XXXXXXX`.
4. Проверьте, что сообщение пришло в нужный Telegram-чат.
5. Проверьте форму на мобильном устройстве и прямые ссылки Telegram/телефона.

Preview deployments лучше оставлять без production-токена либо подключать к отдельному тестовому боту.

## 5. Включить общий rate limit

Встроенный лимит формы — дополнительная best-effort защита одного serverless-инстанса. Для общего ограничения:

1. Откройте **Project → Firewall → Configure → New Rule**.
2. Условие: путь равен `/api/contact`, метод равен `POST`.
3. Выберите **Rate Limit → Fixed Window**, ключ — IP.
4. Начните с 5 запросов за 10 минут и действия **Log**.
5. После проверки ложных срабатываний переключите действие на ответ `429`.

Прямой Telegram и телефон уже оставлены на сайте как запасной канал, если Telegram Bot API временно недоступен.
